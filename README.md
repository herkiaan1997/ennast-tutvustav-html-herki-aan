# Ülesanne01 – ennast tutvustav veebileht

See projekt on tehtud TAK26 programmeerimise sissejuhatuse õppeülesande jaoks.

Minu nimi on **Herki Aan** ja õpin tarkvaraarendust. Selle veebilehega tutvustan ennast, oma huvisid ja seda, mida praegu õpin. Kujunduses kasutasin valget ja sinist värvi ning tehnilisemat, kandilisemat stiili.

## Veebilehel on

- minu tutvustus ja foto;
- hobid ja huvid;
- hele ja tume režiim;
- telefoni ja tahvli jaoks kohanduv kujundus;
- animatsioonid ja interaktiivsed elemendid;
- retrostiilis DX-Ball mini-mäng.

## Kasutatud tehnoloogiad

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Projekti failid

- `index.html` – veebilehe sisu ja struktuur
- `style.css` – kujundus
- `script.js` – interaktiivsus ja mini-mäng
- `minufoto.png` – minu foto
- `README.md` – projekti kirjeldus

## Kuidas veebilehte avada?

Ava projekti kaust ja käivita fail `index.html` veebibrauseris.

## DX-Ball mini-mäng

Mängu avamiseks vajuta avalehel minu fotole.

Eesmärk on palliga purustada kõik klotsid. Iga purustatud klots annab **100 punkti**.

Mängu saab juhtida:
- hiirega;
- vasaku ja parema nooleklahviga;
- telefonis või tahvelarvutis sõrmega.

Kui kõik klotsid on purustatud, kuvatakse lõppskoor ja teade:

**„Mäng läbi! Aitäh mängimast!”**
